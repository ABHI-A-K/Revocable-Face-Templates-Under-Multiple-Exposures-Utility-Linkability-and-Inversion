# Before release

1. Extract the main ZIP and upload its contents to your repository root. Keep the repository private while reviewing confidential results.
2. Choose a code/data license with the rights holders. The current LICENSE reserves rights; it is not an open-source grant. Third-party licenses remain separate.
3. Add the real repository URL, release tag and eventual archive DOI to CITATION.cff.
4. Review optional biometric caches separately before public distribution. Keep photographs and restricted model weights outside the repository.
5. Run verification and figure regeneration in a clean environment, then complete external dependencies before claiming full reproduction.
6. Inspect notebook input paths and dataset identity metadata. No credentials should be added.
7. Create a versioned release and share its link so the manuscript citation and reproducibility paragraphs can reference the exact release.
