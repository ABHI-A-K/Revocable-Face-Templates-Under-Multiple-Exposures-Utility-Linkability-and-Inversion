# Scope and known limitations

The release supports regeneration of the manuscript figures and shared numerical macros from supplied evidence, together with checks of 672 CFP aggregate estimates, paired differences and encoder table rows. Original code, configurations, exact partitions, key schedules and available trial-level evidence are supplied. LFW recognition replay is supported with optional frozen caches.

The complete image-to-attack pipeline was not rerun during packaging. Full reproduction requires external datasets and model weights, notebook-specific environments and some predecessor artifacts. CFP-ENC result archives do not include every E01A cache, E01B fitted artifact or E03 attack-evidence file needed by E04; these must be regenerated. There is no single complete historical dependency lock. Root requirements pin the separate analysis environment; archived runtime records describe experiment environments.

The original standalone LFW E01 extraction notebook was not located. Its saved evidence is included and the recovered LFW encoder extraction code verifies original preprocessing against frozen embeddings. The LFW encoder work checkpoint supplies its scripts and results. One damaged cached PCA file, if listed in verification/excluded_assets.json, is excluded; evaluate.py refits PCA from embeddings. No missing empirical values are invented.

Identity assignment checks in this package are scoped to available manifest schemas, not an independent re-annotation or certification of all labels. Dataset identity/path strings are retained where they define protocols. Images, crop chunks and weights are excluded. Optional embeddings/templates may reveal identity information and should be reviewed before release.

Exact bits can depend on model bytes, image decoding, QR/PCA conventions, library versions and threshold ties. Match the recorded runtime for exact checks. Read decision CSVs with float_precision="round_trip" where nextafter thresholds matter. Do not silently weaken gates to force a pass. Hash integrity does not establish scientific correctness.

The original CFP baseline and later encoder replication must not be pooled. LFW second-encoder evidence covers recognition only. Bootstrap intervals are conditional and pointwise, with repeated identity dependence retained. No image-generation or camera attack, hardware latency or energy benchmark is established by this package.

Suggested statement: “The repository provides archived experiment code, protocol records, machine-readable results, and scripts for regenerating the manuscript figures and checking numerical values. Full experimental reruns require the stated datasets, checkpoints and intermediate artifacts. Scope and remaining dependencies are documented.”

A stronger end-to-end claim requires a documented clean full run.

## Verification completed during packaging

The LFW encoder recognition script was executed using frozen embeddings. Its 640 fold rows, seed summaries and final summaries agree with the archived evidence within rtol=1e-10 and atol=1e-12. The damaged MobileFaceNet fold-4 PCA cache was regenerated by this run and is explicitly identified in verification/lfw_replay_comparison.json. This is a recognition replay, not new image extraction or attack execution. All manuscript figure scripts completed.
